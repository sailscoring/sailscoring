# Contributors

Sail Scoring has no code contributors other than its maintainer. Every line so
far was written by **Mark McLoughlin** with the assistance of **Claude**
(Anthropic), and the commit history says so honestly — you will find the
`Co-authored-by` trailer on most of it. Outside contributions are welcome; see
[`CONTRIBUTING.md`](CONTRIBUTING.md) for how to make one.

Writing code is no longer the scarce input it once was. Knowing which results
are *wrong* — which discard the sailing instructions actually intend, which
column a scorer expects where, which step of a rating calculation quietly
disagrees with the certificate — still requires people who have done the job for
real and are willing to say so precisely. The people below did that.

## Getting on this list

File a bug, report a scoring result you believe is wrong, or send a series that
doesn't behave — [issues](https://github.com/sailscoring/sailscoring/issues) or
mark@hyc.ie. A reproducible report of a wrong result is the single most valuable
thing anyone can contribute to a scoring engine.

If you send feedback, the assumption is that you are happy to be credited here —
name and club, nothing more. Say the word and you will be left off, or listed
differently; there is no wrong answer and no need to explain.
